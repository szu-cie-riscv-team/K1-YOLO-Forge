# 图像与标签

本目录存放用户输入。原始数据保持只读；转换、映射和划分结果写入 outputs/<项目>/<run-id>/prepare/dataset，避免不同实验互相覆盖。

```text
data/
├── raw/                 # 标注工具导出的 images/、labels/、类别名称、分组清单
├── calibration/images/  # 独立校准原始图片；清单写入各次 outputs
├── replay/              # 保留 COCO 类模式所需的原类回放数据
└── retained_val/        # 原类独立回归集
```

首版输入约定为 YOLO detection TXT：每行 `class_id center_x center_y width height`，坐标归一化至 `[0,1]`。标注工具本身可自行选择；其他格式应经过明确的转换步骤。

- 原始自定义标签使用自己的局部连续 ID，类别映射程序另行生成模型输出 ID，不能要求标注人员手工填写混合后的稀疏 ID。
- 分组信息至少包含图像路径和采集批次/视频 ID；按分组拆分，另查重复文件及近重复帧。
- 空标签可以表示确认过的无目标图像；缺少标签不能自动解释成背景。
- 保留类模式下，项目图中可见的保留类也要标注或采用经过验证的忽略/补标策略，避免被当作背景。
- 颜色任务覆盖光照、曝光、白平衡、距离与部署视角；禁止改变类别语义的色相增强。
- 校准只使用训练部分或独立校准采集，固定最终 test 不参与选择模型、阈值或量化配方。
- 图像、标签和大模型不默认进入 Git；每次运行保存数据清单、划分、类别表和 SHA-256。
- `data.split.mode=counts` 时可指定训练、验证和测试的实际图片张数；先按组隔离，再抽样。数量或类别覆盖不足时报错，不复制图片凑数。原图未被选中时也不删除。
